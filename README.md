# AI Resume & Placement Assistant

## Deploy to Render

The repository includes [`render.yaml`](./render.yaml), which defines a Render
Python web service for FastAPI and a React static site. Production uses Gemini
for AI and MongoDB Atlas for persistence; local development can continue to use
Ollama and local MongoDB. The backend runtime is pinned to Python 3.12.10 in
both `render.yaml` and the root `.python-version` file.

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint** and select the repository containing
   `render.yaml`.
3. When prompted, provide the backend secrets `GEMINI_API_KEY` and `MONGO_URI`.
   The Blueprint generates `JWT_SECRET`.
4. Deploy both services. The API health check at `/health` confirms MongoDB
   connectivity.

### Render environment variables

Set these on the **backend web service**:

| Variable | Required value |
| --- | --- |
| `APP_ENV` | `production` (set by the Blueprint) |
| `AI_PROVIDER` | `gemini` (set by the Blueprint) |
| `GEMINI_API_KEY` | Secret key from Google AI Studio |
| `GEMINI_MODEL` | `gemini-2.5-flash` (set by the Blueprint; change if desired) |
| `MONGO_URI` | MongoDB Atlas SRV URI, for example `mongodb+srv://<user>:<url-encoded-password>@<cluster-host>/?retryWrites=true&w=majority` |
| `MONGO_DB_NAME` | `placement_assistant` (set by the Blueprint) |
| `JWT_SECRET` | Long random secret; generated by the Blueprint |
| `CORS_ORIGINS` | `https://ai-resume-placement-assistant.onrender.com` (set by the Blueprint) |
| `NUM_QUESTIONS` | `6` (set by the Blueprint; optional to change) |

Set this **build-time variable on the frontend static site**:

| Variable | Required value |
| --- | --- |
| `REACT_APP_API_BASE` | `https://ai-resume-placement-api.onrender.com` (set by the Blueprint) |

The default Render service names in `render.yaml` produce the URLs above. If you
rename either service or attach a custom frontend domain, update
`REACT_APP_API_BASE` on the static site and `CORS_ORIGINS` on the API service,
then redeploy. Create React App embeds `REACT_APP_API_BASE` during the frontend
build; it is not a secret.

### MongoDB Atlas checklist

- Create a database user with a strong password and only the database
  permissions the app needs. The application reads and writes user, resume,
  and interview records, so grant that user `readWrite` on `placement_assistant`.
- Put the Atlas connection string in Render's `MONGO_URI` secret, URL-encoding
  special characters in the username or password. Atlas SRV URIs use TLS by
  default; if no `authSource` query option is present, the backend uses
  `admin`, which is the default authentication database for Atlas database users.
- Allow network access from Render in Atlas. Render free services do not have a
  fixed outbound IP; if an IP allowlist is required, use a paid Render plan with
  fixed egress or, if you accept the exposure, add `0.0.0.0/0` to Atlas's IP
  access list while protecting the cluster with strong credentials and
  least-privilege permissions.
- Visit `https://ai-resume-placement-api.onrender.com/health`; a healthy
  response includes `"database":"ok"`.

The backend logs only the MongoDB URI source and scheme, selected database,
TLS status, timeout, and a redacted failure category. It never logs the URI,
password, API key, or JWT secret. For `server_selection_timeout`, check Atlas
Network Access, outbound IP access, DNS, and TLS; for authentication or
authorization categories, check the database user's credentials and role.

Do not put Gemini or MongoDB credentials in frontend variables or commit them
to the repository. Gemini API usage can be subject to account quotas and
charges; check the current Google AI Studio terms and limits before deployment.

## Local development

Copy `.env.example` to `.env` in the repository root and keep
`AI_PROVIDER=ollama`. Install/start Ollama with `llama3.2:1b`, and set up
MongoDB locally. Copy `frontend/.env.example` to `frontend/.env`.

Run the backend from the repository root:

```powershell
python -m uvicorn backend.interview:app --host 127.0.0.1 --port 8002
```

In another terminal:

```powershell
Set-Location frontend
npm ci
npm start
```

The frontend runs at `http://localhost:3000`; its API base is configured by
`REACT_APP_API_BASE` in `frontend/.env`.
